支持

欢迎来到 Cloakly 支持中心。查找常见问题的答案，了解如何充分利用文档脱敏工具。

常见问题

入门指南

如何开始使用 Cloakly？

  1. 打开 Cloakly
  2. 点击"打开文件"选择 PDF 或图片
  3. 点击"开始扫描"自动检测敏感信息
  4. 审核检测到的项目
  5. 点击"安全导出"生成脱敏文档

支持的文件格式

Cloakly 支持哪些文件格式？

  • PDF 文件（原生和扫描版）
  • 图片格式：PNG、JPEG、HEIC

Cloakly 内置 OCR（光学字符识别）功能，可以处理扫描文档和带有文字的图片。

检测功能

Cloakly 可以检测哪些类型的信息？

  • 姓名和地址
  • 电话号码
  • 电子邮件地址
  • 政府证件号码（护照、驾照等）
  • 银行账号
  • 信用卡号
  • 图片和扫描文档中的人脸
  • 您定义的自定义模式

隐私与安全

我的数据安全吗？

是的！Cloakly 完全在您的 Mac 本地处理所有内容。您的文档永远不会上传到云端或任何外部服务器。所有处理都在您的设备上进行，确保完全的隐私和安全。

Cloakly 需要互联网连接吗？

不需要。Cloakly 完全离线工作。只有在从 Mac App Store 初始下载和应用内购买时才需要互联网。

购买与授权

如何恢复购买？

打开 Cloakly → 设置 → 点击"恢复购买"。如果使用相同的 Apple ID 购买，您的专业版将自动恢复。

免费版和专业版有什么区别？

  • 免费版：每月处理最多 5 个文档，包含所有核心功能
  • 专业版（$29.99）：无限文档、批量处理、自定义检测规则、优先支持

专业版是一次性购买，无需订阅。

技术要求

系统要求是什么？

  • macOS 14.0 或更高版本
  • Apple Silicon 或 Intel 处理器
  • 约 200 MB 磁盘空间

批量处理

如何使用批量处理？（专业版功能）

  1. 点击工具栏中的"批量处理"按钮
  2. 添加多个 PDF 或图片文件
  3. 配置检测设置
  4. 点击"开始批量处理"
  5. 审核并导出所有处理过的文档

故障排除

应用程序未检测到某些信息。我该怎么办？

  • 使用手动选择工具标记其他区域
  • 检查文档质量是否足够（对于扫描文档）
  • 对于自定义模式，在设置 → 检测规则中添加

导出失败。出了什么问题？

  • 确保您对目标文件夹有写入权限
  • 检查是否有足够的磁盘空间
  • 对于密码保护的 PDF，您必须先解锁
