サポート

Cloakly サポートセンターへようこそ。よくある質問の答えを見つけ、文書編集ツールを最大限に活用する方法を学びましょう。

よくある質問

はじめに

Cloakly の使い方は？

  1. Cloakly を開く
  2. 「ファイルを開く」をクリックして PDF または画像を選択
  3. 「スキャン開始」をクリックして機密情報を自動検出
  4. 検出された項目を確認
  5. 「安全にエクスポート」をクリックして編集済み文書を生成

サポートされているファイル形式

Cloakly はどのファイル形式をサポートしていますか？

  • PDF ファイル（ネイティブとスキャン版の両方）
  • 画像形式：PNG、JPEG、HEIC

Cloakly には OCR（光学文字認識）が組み込まれており、スキャン文書やテキスト付き画像を処理できます。

検出機能

Cloakly はどのような情報を検出できますか？

  • 氏名と住所
  • 電話番号
  • メールアドレス
  • 政府発行の ID 番号（パスポート、運転免許証など）
  • 銀行口座番号
  • クレジットカード番号
  • 画像やスキャン文書内の顔
  • カスタム定義パターン

プライバシーとセキュリティ

データは安全ですか？

はい！Cloakly はすべてを Mac 上でローカルに処理します。文書がクラウドや外部サーバーにアップロードされることはありません。すべての処理がデバイス上で行われ、完全なプライバシーとセキュリティを確保します。

Cloakly にはインターネット接続が必要ですか？

いいえ。Cloakly は完全にオフラインで動作します。インターネットが必要なのは、Mac App Store からの初回ダウンロードとアプリ内購入時のみです。

購入とライセンス

購入を復元するにはどうすればよいですか？

Cloakly を開く → 設定 → 「購入を復元」をクリック。同じ Apple ID で購入した場合、プロフェッショナル版が自動的に復元されます。

無料版とプロフェッショナル版の違いは何ですか？

  • 無料版：月5文書まで処理可能、すべてのコア機能を含む
  • プロフェッショナル版（$29.99）：無制限の文書、バッチ処理、カスタム検出ルール、優先サポート

プロフェッショナル版は買い切りで、サブスクリプションは不要です。

技術要件

システム要件は何ですか？

  • macOS 14.0 以降
  • Apple Silicon または Intel プロセッサ
  • 約 200 MB のディスク容量

バッチ処理

バッチ処理の使い方は？（プロフェッショナル版機能）

  1. ツールバーの「バッチ処理」ボタンをクリック
  2. 複数の PDF または画像ファイルを追加
  3. 検出設定を構成
  4. 「バッチ処理を開始」をクリック
  5. 処理されたすべての文書を確認してエクスポート

トラブルシューティング

アプリが一部の情報を検出しません。どうすればよいですか？

  • 手動選択ツールを使用して追加領域をマーク
  • 文書の品質が十分かどうか確認（スキャン文書の場合）
  • カスタムパターンの場合、設定 → 検出ルールで追加

エクスポートが失敗しました。何が問題ですか？

  • 保存先フォルダへの書き込み権限があることを確認
  • 十分なディスク容量があることを確認
  • パスワード保護された PDF の場合、まずロックを解除する必要があります
